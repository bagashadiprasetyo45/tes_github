Kamu hosting di GitHub Pages?
GitHub Pages hanya support file statis (HTML/CSS/JS) jadi PHP & MySQL tidak akan jalan dan login.php akan terlihat sebagai file mentah / 404.

Supaya tetap terhubung ke database, jangan pakai GitHub Pages. Pakai hosting PHP+MySQL gratis seperti InfinityFree, FreeHosting, Railway, atau Hostinger. Tetap push code ke GitHub, tapi deploy PHP-nya ke hosting tersebut.
File index.html ini hanya agar GitHub tidak error, logic aslinya tetap di index.php & login.php.
